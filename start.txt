====================================================================
ILD-OHIF-Tool — Windows local run guide (PowerShell)
====================================================================
Run every command below in PowerShell, not Git Bash — Git Bash
(MSYS) silently rewrites paths like "/ohif/" into a Windows path
under the Git install dir (e.g. "C:/Program Files/Git/ohif/"),
which breaks env vars such as PUBLIC_URL.

1. Orthanc (DICOM server)
--------------------------------------------------------------------
Nothing to do — runs automatically as a Windows service.

  Get-Service -Name Orthanc

Should show Running / Automatic. If Stopped, from an elevated
PowerShell: Start-Service Orthanc


2. Start the MONAI Label server
--------------------------------------------------------------------
  cd C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool
  C:\Users\GoFOODAppPC\miniconda3\envs\monai081\python.exe -m monailabel.main start_server --app radiology --studies http://localhost:8042/dicom-web --conf models nnunet_lung,nnunet_ild,nnunet_airways,sam2_ild

Wait for: Uvicorn running on http://0.0.0.0:8000
Keep this terminal open — closing it stops the server.


3. Open the viewer
--------------------------------------------------------------------
Browse to http://localhost:8000/ohif/
Studies already uploaded to Orthanc are listed automatically.


4. Upload a new study
--------------------------------------------------------------------
Go to http://localhost:8042/ui/app/, click Upload, drag in .dcm
files or a .zip of the study folder. Appears immediately, no restart.


5. Dev workflow — hot-reload (for editing the extension)
--------------------------------------------------------------------
Use this while actively coding. It recompiles on save; just refresh
the browser after each change.

5a. One-time setup (skip if plugins\ohifv3\Viewers already exists)

  cd C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3
  git clone https://github.com/OHIF/Viewers.git
  cd Viewers
  git checkout d8ef36ed24466988586e19b855d2bbb86f8c657a
  New-Item -ItemType Junction -Path extensions\monai-label -Target C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\extensions\monai-label
  New-Item -ItemType Junction -Path modes\monai-label -Target C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\modes\monai-label
  git apply ..\extensions.patch
  Copy-Item ..\config\monai_label.js platform\app\public\config\monai_label.js
  yarn config set workspaces-experimental true
  yarn install

(Junctions don't need admin PowerShell or Developer Mode, unlike
symlinks.)

5b. Run the dev server (needs the MONAI Label server from step 2
    running in another terminal)

  cd C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\Viewers\platform\app
  $env:NODE_ENV="development"; $env:APP_CONFIG="config/monai_label.js"; $env:OHIF_PORT="3002"
  $env:PROXY_TARGET="/proxy/dicom"; $env:PROXY_DOMAIN="http://localhost:8000"
  $env:PROXY_PATH_REWRITE_FROM="/proxy/dicom"; $env:PROXY_PATH_REWRITE_TO="/proxy/dicom"
  npx webpack-dev-server --config .webpack/webpack.pwa.js

Browse to http://localhost:3002/ohif/ once it says "compiled
successfully". Edits under extensions\monai-label\src recompile
automatically.


6. Deploy local changes to :8000/ohif/ (production build)
--------------------------------------------------------------------
Step 3's viewer serves a separately built copy — it does NOT pick up
edits under extensions\monai-label or modes\monai-label on its own.
Run this to rebuild and push your changes there.

Only needed when you want changes live on :8000, not for every edit
— use the hot-reload dev server (step 5) for day-to-day work.

  cd C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\Viewers\platform\app
  $env:NODE_ENV="production"; $env:APP_CONFIG="config/monai_label.js"
  $env:PUBLIC_URL="/ohif/"; $env:QUICK_BUILD="true"
  yarn run build
  Remove-Item -Recurse -Force C:\Users\GoFOODAppPC\miniconda3\envs\monai081\Lib\site-packages\monailabel\endpoints\static\ohif
  Copy-Item -Recurse dist C:\Users\GoFOODAppPC\miniconda3\envs\monai081\Lib\site-packages\monailabel\endpoints\static\ohif

Then restart the MONAI Label server (step 2). Skip "yarn install"
here — it's slow and only needed if package.json/yarn.lock changed.


7. Troubleshooting
--------------------------------------------------------------------
- "CLI for webpack must be installed" during build:
  Don't let it auto-install via npm — it errors on this repo's
  pre-existing peer-dep conflicts. Instead:

    cd C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\Viewers
    yarn add -D webpack-cli@^5 -W

- Hovering the edge of a Rectangle/Freehand ROI doesn't glow like a point
  handle does: this needs the "@cornerstonejs+tools+2.2.3.patch" file
  (widens the hover hit-zone from 6px to 10px) to have been applied.
  It auto-applies via the "postinstall" script every time "yarn install"
  runs (patch-package). If it's missing after setup, reapply manually:

    cd C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\Viewers
    npx patch-package

- Build output looks stale / your fixes aren't showing up:
  Confirm extensions\monai-label and modes\monai-label under Viewers
  are junctions, not real folders:

    Get-Item C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\Viewers\extensions\monai-label

  Attributes should include "ReparsePoint". If not, delete and
  recreate as junctions (see step 5a).

- :8000/ohif/ loads blank, console shows errors like
  "Not allowed to load local resource: file:///C:/Program Files/...":
  The build was run in Git Bash instead of PowerShell (see note at
  top) and baked a broken PUBLIC_URL into index.html. Rebuild in
  PowerShell (step 6).

- Rebuild finishes suspiciously fast (a few seconds) and the app is
  still blank / index.html looks unminified with a plain "app.js"
  script tag (no hash): stale webpack cache produced a broken
  index.html. Clear it and rebuild:

    Remove-Item -Recurse -Force C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\Viewers\node_modules\.cache
    Remove-Item -Recurse -Force C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\Viewers\platform\app\node_modules\.cache
    Remove-Item -Recurse -Force C:\Users\GoFOODAppPC\Documents\Github\ILD-OHIF-Tool\plugins\ohifv3\Viewers\platform\app\dist

  Then rerun step 6's build. A clean build takes about a minute.


8. Shut down
--------------------------------------------------------------------
Ctrl+C (or close) the MONAI Label terminal, and the dev-server
terminal if you started one. Leave Orthanc's service running — it's
idle/lightweight when not in use.
